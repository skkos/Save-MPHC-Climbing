# Save MPHC Climbing

The climbing gym at Manhattan Plaza Health Club — 482 W 43rd St, Hell's Kitchen —
closes on 30 September 2026 after 34 years. It opened in 1992 and is the oldest
continuously operating climbing gym in New York City.

**Live page:** https://skkos.github.io/Save-MPHC-Climbing/

This repo hosts that one page. `index.html` is the whole site — no build step,
no dependencies. Edit it here and GitHub Pages redeploys in about a minute.

- Petition: https://www.change.org/p/save-mphc-climbing-gym-from-closure
- Pricing pledge: https://forms.gle/QeXEF3GZtaA2TqLY6
- Contact: savemphc@gmail.com

Run by members of the MPHC climbing community. Not affiliated with, authorised
by, or run by Manhattan Plaza Health Club or Related Companies.
